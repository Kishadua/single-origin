# Single Origin — concept website

Freeze-dried Indian specialty coffee from three named hills: Chikmagalur, Coorg and Araku.
Concept site for a brand pitch (Nov 2026). **Five seconds to origin.**

## Pages
- `index.html` — brand home: the address problem, origin switcher, five-second timer, campaign, the tin, merch, Platform 5 launch.
- `product.html` — shop: gallery, origin / format / subscription options, bag drawer, Discovery Box, merch.
  Link straight to an origin with `product.html#chikmagalur`, `#coorg` or `#araku`.

## Run locally
Open `index.html` in a browser. No build step, no dependencies.

## Publish on GitHub Pages
1. Create a new repository and upload everything in this folder (keep the `img/` folder).
2. Go to **Settings → Pages**, set Source to **Deploy from a branch**, branch `main`, folder `/ (root)`.
3. The site appears at `https://<your-username>.github.io/<repo-name>/` after a minute or two.

## Notes
- This is a concept: "Add to bag" works, but checkout and the launch sign-up do not send or charge anything.
- Prices, refill and Discovery Box details are proposed.
- Fonts load from Google Fonts (Archivo, Archivo Black, DM Sans, IBM Plex Mono).
- Imagery is AI-generated campaign artwork.
